# Windows preflight W2 — 18.11.2026

Это отдельный локальный прототип Qt ADS для решения ARU-55. Основное приложение ещё
использует прежний docking. Это не release и не заявление о готовности MVP.

Распакуйте всю папку LODANDSY-W2-Preflight и запустите LODANDSY-W2-Preflight.exe.
Не переносите один .exe без _internal. Python и Qt включены в папку. Требуется Windows
10/11 x64 с системной ICU; проверенная машина — Windows 10 build 19045.
На машине без установленного Python запуск ещё должен быть проверен владельцем.

В меню «Проект» создайте тестовый мир в новой пустой папке. В Tree через контекстное
меню создайте A/B и дочерние карточки, откройте два редактора двойным щелчком и введите
разный текст. Autosave/Ctrl+S и повторное открытие проекта используют SQLite, как в
основном приложении. Не используйте единственную копию реального мира для preflight.

Обязательные сценарии до миграции:

1. Запуск на чистой Windows без Python, в том числе из пути с кириллицей.
2. Dock влево/вправо/вверх/вниз, CENTER/tab, split, insert между окнами и у fixed panels.
   Подсветка должна совпадать с результатом; Escape отменяет перенос.
3. Floating и возврат в dock, системный заголовок, minimize/maximize/restore.
   При drag maximized окна точка захвата остаётся под курсором.
4. Выбор B в Tree не меняет редактор A; правки A/B, rename, закрытие/reopen и Undo
   сохраняют независимость. После перемещений и повторного открытия проекта текст тот же.
5. Preflight → Save test layout; затем изменить размещение/закрыть документы и
   Restore test layout. После перезапуска сначала открыть тот же проект, затем восстановить
   тестовый layout: он содержит ID открытых карточек и состояние ADS отдельно от мира.
6. Два монитора, разные DPI, перенос между ними, исчезновение монитора и восстановление
   видимости. Автоматически проверены два экрана 1920×1080 при одинаковых 96 DPI;
   это не проверка mixed DPI и не ручная приёмка.
7. При любом отклонении сохранить точный сценарий и наблюдаемый результат. Не считать
   conditional W2 принятым для миграции, пока обязательные проверки не прошли.

Программная самопроверка (не заменяет сценарии мышью):

```powershell
.\LODANDSY-W2-Preflight.exe --self-test --report result.json
```

Она создаёт временный мир, проверяет два настоящих редактора, направления размещения,
float/maximize/redock, layout, fixed panels, reopen/Undo и SQLite save. После завершения
в result.json должен отсутствовать error/startup_error, значения проверок — true.
Файл runtime_prefix указывает на встроенный _internal. Первый frozen smoke после
исправления ICU завершился с кодом 0 при PATH без Python, но на машине с установленным
Python. Это ограниченное доказательство, а не чистая Windows.

Сборка: Python 3.14.8; Qt/PySide6-Essentials/shiboken6 6.11.2; Qt ADS bindings 5.1.1;
PyInstaller 6.22.3 и hooks 2026.10. Исходники прототипа и приложения включены в source/,
зависимости — requirements-w2-preflight.txt, spec/script — source/prototypes/.
Лицензии и источники: THIRD-PARTY-W2.md и LICENSES/.
