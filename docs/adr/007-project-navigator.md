# ADR-007: единая навигация проекта

Группировка и Card-only DnD **заменены ADR-013** по новому запросу владельца в итерации 3.
Ниже сохранено решение и приёмка прежнего среза, не контракт нового дерева.

Статус: ARU-69, согласованный владельцем макет с уточнениями 19.11.2026; реализация
прошла [ручную приёмку нового ZIP](../validation/2026-11-19-owner-acceptance.md).
Проверка поставки без Python остаётся в ARU-64.

Контекст: Cards уже имеют иерархию, Maps/Tables — независимые модульные документы.
Верхние меню объектов конкурировали с деревом. Новый контракт требует одного дерева,
сохраняя fixed panels, WindowManager, Qt ADS и обратную совместимость проектов.

Варианты: расширить каноническую Entity-иерархию всеми модулями либо представить
независимые summaries в общем UI navigator. Выбран второй: ProjectTreeModel группирует
Card summaries и (ID,title) модулей, не владеет payload, SQL и предметными операциями.
CardCollection не меняется; DnD разрешён только внутри раздела Cards и валидируется
прежним application/domain путём. Maps/Tables/секции нельзя перенести в Card-иерархию.

Узлы имеют UI key kind:ID; открытие проходит через AppController.open_entity и
существующий open_document/WindowManager. Данные и операции остаются у модулей.
Inspector показывает выбранную Card либо readonly summary карты/таблицы; выбор
не переназначает редакторы и не смешивается с active window.

Владелец уточнил макет: поиск скрыт под кнопкой; создание — кнопка «+» с dropdown;
плюсы у карточек убрать, дочерние — через контекстное меню. Реализованы один header
и одна пара настоящих кнопок у selected/hover row: открыть и действия. Это не тысячи
виджетов для всех строк. Выбранная строка и клавиатурный Tab работают без hover.
Enter открывает, Insert показывает создание, F2 переименовывает, Delete подтверждает
удаление, Shift+F10 открывает меню. Контекст Cards включает parent/order/link.

SQLite schema 3 не изменена. UI state version 1 расширен необязательными полями
navigator_selected/expanded/scroll. Прежние selected/expanded Card IDs читаются;
при старом UI state новый раздел Cards раскрывается, чтобы документы оставались
доступными. Повреждённые/пропавшие keys не меняют данные мира.

Проверки: test_project_navigator.py — import/create, Enter/inline open/focus,
context child/rename/delete, независимость редактора, Card-only DnD, проектный
save/switch/reopen, прежний UI state и collapse preservation. Старые Card-сценарии
сохранены с новым местом корня под разделом. Исправлена найденная при teardown ошибка
eventFilter после удаления Qt view. Требуется итоговая ручная проверка focus/DPI.

Пересмотр: новые виды навигационных объектов или подтверждённая необходимость
общей предметной иерархии; текущая группировка сама по себе такую модель не вводит.
