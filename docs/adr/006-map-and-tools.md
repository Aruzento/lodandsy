# ADR-006: встроенные Map M1 и Tools

Статус: реализация согласованной границы ARU-67/68, автоматические проверки пройдены;
владелец 18.11.2026 подтвердил все перечисленные сквозные сценарии Map/Tools полной сборки.
Полная сборка проверялась с Python; clean-Windows проверка поставки остаётся открытой.

MapDocument и MapPin — неизменяемые domain values без Qt/SQL, UUID и нормализованные
координаты [0,1]. Подпись маркера независима от названия Card. Ссылка хранит UUID и
допускает разрыв; Card не копируется в маркер. ModuleSession — один application write
path с адресными событиями и QUndoStack каждой карты (200 команд на сессию).
Окна не владеют данными; закрытие/перемещение документа не меняет payload.
AppController.open_document явно различает card-editor:UUID, map:UUID, table:UUID
и dice; неизвестный ключ отклоняется. Это dispatch встроенных модулей, не plugin SDK.

Выбран штатный QGraphicsView/Scene, уже предусмотренный MVP как начальный кандидат:
изображение и movable items, без второго renderer/зависимости, tiles или слоёв.
Импорт/декодирование выполняются в pool из двух worker threads; QImage возвращается
в GUI, QPixmap/виджеты создаются только там. До публикации карты проверяется реально
скопированный ресурс. Повреждённое/пропавшее изображение оставляет диагностическую
сцену с редактируемыми маркерами. Пути не могут выйти из assets/проекта.

Пределы M1: PNG/JPEG/BMP/GIF/WebP, 64 MiB encoded / 16 млн пикселей на изображение;
LRU декодированных QImage 64 MiB. Открытые сцены дополнительно держат QPixmap, поэтому
много одновременно открытых крупных карт увеличивает память. SVG не принимается.
Камера — локальный UI state, не часть world revision.

Варианты расширения GPU/tiles отложены до измеренной необходимости. Измерение на
Windows/Qt 6.11.2: искусственный PNG 4000×4000 (56 391 bytes), import 309.91 ms,
GUI timer 29 ticks, max gap 15.32 ms; refresh 1000 markers 41.07 ms. Это один локальный
прогон, не SLA и не проверка всех изображений/видеокарт. prototypes/map_benchmark.py.

Tools используют ограниченный regex NdM±K без eval: 1–1000 кубиков, 2–1 000 000 граней,
|K|≤1 000 000 000; d20 означает 1d20. SystemRandom в продукте, injectable RNG в тестах.
Результат показывает каждый кубик, modifier и total; повтор и копирование не меняют мир.
RandomTable хранит упорядоченные текстовые строки. Все непустые строки равновероятны;
пустые исключены и явно описаны в UI. Ввод в активной ячейке обновляет application
state сразу, поэтому Ctrl+S/закрытие видят ещё не завершённое редактирование.

SQLite schema 3 хранит module payload с версией 1 внутри канонической БД; сохранение
Cards/maps/tables/assets — один snapshot/transaction. Map→asset — FK; pin→Card — UUID
без FK. Схемы 1/2 безопасно мигрируют с backup, unknown payload не перезаписывается.
Проверки: test_modules.py, test_workspace_state.py и source/frozen windows_smoke.
Clipboard writer повторяет ограниченно при Windows COM busy и сообщает об отказе.

Пересмотр: новый тип ресурса/модуль, измеренная нехватка памяти/производительности,
изменение синтаксиса кубиков, вероятностей или ссылок — по согласованию с владельцем.
