# ADR-038 — видимость подписи портала и совместимость Map9

26.11.2026. Принято по прямому заданию владельца, ARU-89 / ARU-91.

## Контекст и решение

Портал сохраняет имя независимо от его отображения. Maps-owned immutable MapPortal
получает hide_label: bool=False после id (старые позиционные конструкторы сохраняют
порядок аргументов). Только bool, не integer/string/null. Создание/редактирование
использует нативный диалог с чекбоксом «Не показывать название на карте».
Изменение проходит через прежний put_vector и адресованный Map Undo; cancel и
смена generation не записывают данные. При конфликте старого portal value Apply
отклоняется. Painter пропускает только drawText; icon/hit-test/double-click остаются.
Player никогда не получал порталы и по-прежнему их не получает.

## Формат и совместимость

MapPayload9 и map_document.payload_version=9; SQLite schema16, Card7 и UIstate4
не меняются. JSON objects.portals хранит hide_label вместе с прежними полями.
Reader принимает Map7/8/9: отсутствие флага означает false, Map7 получает прежние
пустые vector collections. Open/load не сохраняет и не меняет байты мира.
Следующее явно запрошенное сохранение пишет9. Старый reader, знающий только7/8,
отклоняет9, а не теряет флаг при записи. Неизвестные будущие версии отклоняются.
Это узкая совместимость согласованного добавочного поля, не legacy-адаптер.
Резервные копии содержат тот же канон UUID/label/hide_label, без преобразования.

## Калибровка и режим измерения

Только MapsService.create_map явно задаёт MapGrid(feet_per_cell=5). Значение по
умолчанию самого MapGrid остаётся None: прежние неизвестные масштабы, включая
отсутствующее JSON поле, остаются неизвестными. Остальные настройки не меняются.
Метрика остаётся существующим UI QSettings maps/measurement (grid/geometry),
выбирается в диалоге сетки, применяется после OK. Формулы расстояний не меняются;
измерение по-прежнему сопровождает перемещение токена в обычном select.

## Проверка и последствия

Покрыты strict type, Map8 missing flag/unknown calibration и отсутствие записи,
Map9 save/reopen/backup/restore, сохранение UUID/имени, cancel/Undo/Redo и двойной
щелчок. Pixel-проверка подтверждает неизменность иконки при исчезновении подписи,
Player-проверка — отсутствие порталов при обоих флагах. Новые зависимости, таблицы
SQLite, event bus, второй writer или Undo не вводятся.
