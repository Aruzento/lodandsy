обычным merge-коммитом и push. После публикации тега создана отдельная ветка.

приложения и другие материалы остались в исходном рабочем дереве.

Поддерживаемая база пользовательских миров — SQLite17, Card8, Map9–10, Actor1,
Table4, Rules1 и Economy1. Изменение канона требует проверенной копии, безопасной
миграции с сохранением UUID и связей, проверки целостности и повторного открытия.

## Реализация

| Задача | Что проверять | Компоненты |
| --- | --- | --- |
| ARU-97 | Быстрое создание папки, уникальное имя среди соседних папок и документов, inline-редактирование, Enter/Escape. Каталог именованного проекта и SQLite создаются до Ctrl+S. | `AppController`, `ProjectController`, `TreePanel`, `ProjectTreeModel` |
| ARU-98 | `[[` открывает поиск у курсора. Одноимённые документы различаются по ветке, типу и ID. Замена и удаление ссылки штатным редактором, Undo/Redo, переход и диагностика удалённой цели. | `RichTextEdit`, `CardEditorWidget`, `EntityPicker`, `EntityQueries`, существующий UUID URI |
| ARU-75, заголовки | Выделение до начала следующего абзаца раньше включало его в форматирование. Теперь изменяются только затронутые абзацы. Уровень хранится в `QTextBlockFormat`, выделение и Undo сохраняются. | `RichToolbar`, текущий codec rich text |
| ARU-75, списки | SVG в пунктах маркированного и нумерованного списка, прежние операции `QTextList`. | `RichToolbar`, `ui/icons.py` |
| ARU-76 | Свёрнутый блок сохраняет название, значение и модификатор. Панель подробностей скрывается целиком, экземпляры контролов и черновики сохраняются. Характеристики по умолчанию развёрнуты. | `AbilityBlock`, `SheetDisclosure`, `GameSheet` |
| ARU-99 | «Заметка» открывает или создаёт Card `note`, либо выбирает существующий инвентарь. Повтор фокусирует обычное плавающее окно Card/Table. | `ProjectController`, `AppController`, `EntityPicker`, Card Editor, `TablesController`, `WindowManager` |
| ARU-91 | Inspector следует за инструментом и активной вкладкой Viewer. Режим выбора показывает фигуру, участника или действие портала. Измерения доступны у выбранного токена. Space восстанавливает контекст при отпускании. | `MapsController`, `MapToolState`, `MapToolbars`, `FogTools`, `VectorTools`, `InspectorPanel`, `WindowManager` |

Виртуальные папки пользуются `CardsService` через обычную транзакцию создания.
Ссылки хранятся в том же rich text HTML. Заметка и инвентарь используют обычные
ключи `card-editor:UUID` и `table:UUID`. MapToolState управляет единственными
контролами карты. Inspector меняет их размещение и видимость. Канонические
форматы, адресный reconcile и инкрементальная запись SQLite используются как в S4.
[ADR-037](../adr/037-unified-map-tool-state.md) · [Визуальный стандарт](../design/UI-SYSTEM.md)

## Производительность S3–S4

Замеры Windows 10, CPython 3.14.8, SQLite 3.50.4. В каждом прогоне пять выборок
после прогрева и серии из 40 изменений HP и перемещений. База замера — `v0.01`.
Для повторения используется `python -m prototypes.v001_persistence_benchmark`
с `--profile small|medium|large --samples 5 --series 40 --report PATH`.

| Профиль, Actor / Item / Map / токены | HP GUI p50 / p95, мс | Токен GUI p50 / p95, мс | Пиковая память, МиБ |

| Малый, 12 / 24 / 3 / 48 | 2,82 / 3,22 → 2,94 / 3,26 | 1,75 / 1,78 → 1,76 / 1,86 | 123,8 → 123,9 |
| Средний, 60 / 120 / 6 / 360 | 3,16 / 3,59 → 3,13 / 3,60 | 3,88 / 4,01 → 3,87 / 4,03 | 132,5 → 133,4 |
| Крупный, 180 / 300 / 12 / 1080 | 4,43 / 5,67 → 3,85 / 4,66 | 6,12 / 6,41 → 6,17 / 6,27 | 155,4 → 155,9 |

| Крупный профиль | GUI p50 / p95, мс | Писатель p50, мс | Изменённые SQL-записи | Байты записи p50 |
| --- | --- | --- | --- | --- |
| Поле Card | 7,58 / 8,64 → 7,63 / 8,98 | 541,78 → 537,03 | 6 → 6 | 2 303 450 → 2 303 450 |
| HP Actor | 4,43 / 5,67 → 3,85 / 4,66 | 539,95 → 534,34 | 6 → 6 | 2 295 250 → 2 295 250 |

| Составное изменение | 70,78 / 71,74 → 72,52 / 75,70 | 460,59 → 467,63 | 195 → 195 | 2 762 650 → 2 738 050 |

На крупной серии p95 по HP составил 3,62 → 3,66 мс, по перемещению токена
5,77 → 5,46 мс. Количество SQL-записей совпало на трёх профилях. Составные
операции остались самым дорогим GUI-сценарием. Времена одной серии характеризуют
машину разработки, а пропорции зависят от мира и устройства хранения.
