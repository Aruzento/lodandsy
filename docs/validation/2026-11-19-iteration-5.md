подтвердил Project/Tools, Tree create/search, отдельные боковые области и empty Inspector.

обновления window binding: `window capture timed out: timed out waiting on channel`.
Click: `coordinate input geometry is unavailable`; set_value native folder input:
`Cannot set a value for an element that is not settable`. Геометрические/мышиные сценарии
и визуальная оценка через capture не выполнены. Qt raster tests не выдаются за screenshots.
Существующий пользовательский Desktop/LODANDSY.exe и его мир не изменялись.

Не проверены владельцем: новый внешний вид23 пунктов, физическая100/125/150% mixedDPI/
два монитора, полнота real mouse crop/drag/floating на новой сборке. Два экрана текущей
машины96DPI; установлен Python. Изолированный PATH frozen smoke не равен clean Windows
без Python; ARU-64 остаётся In Progress. Предыдущая W2/iteration4 приёмка не переносится
на новый редизайн. Product scope не требует нового согласования; требуется ручная приёмка.
