Отслеживаемые файлы были чистыми. Локальные вложения и материалы оставлены в их
исходном состоянии. Архив `v.5.rar` найден. В трёх интересующих скриптах изучены

указания монеты. Владелец подтвердил SQLite17 для новых тестовых миров и отказ от
переноса. Проверка исходного commit велась в отдельной распаковке Git archive.

пользовательских наборах номиналов. При одном промежуточном native-прогоне Windows
OLE удерживал буфер дольше первоначального окна повтора. Для типизированной записи
расширено окно повтора, подтверждение сверяет текст и MIME. Регрессионный тест
имитирует пять отказов перед успешной шестой записью.

Source и frozen smoke прошли на Windows. Проверка совпадения исходников с EXE
сравнила 123 модуля, расхождений, отсутствующих и устаревших runtime-модулей нет.
Smoke включает нативный clipboard, подтверждение монет, создание и рестарт мира,
плавающее окно лута, сохранение на кириллическом пути и восстановление backup.
Отдельный прогон записал результаты в одном процессе и открыл тот же мир в новом:
оба результата, параметры и окна восстановились. Целевой native smoke T3 также
прошёл с `QT_SCALE_FACTOR=1.25` и `2`. Проверка распакованного ZIP фиксируется
отдельными отчётами `tools-t3-portable-smoke.json` и `tools-t3-package-verification.json`
рядом с кандидатом.
