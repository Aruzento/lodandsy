## Изменения и границы

ADR-036 фиксирует единственный Map канон и compositor. domain/map_measurements.py —
чистая калибровка: F/C×max(|dx|,|dy|) либо F/C×hypot(dx,dy). Это не путь/стоимость
движения. F=None даёт диагностику. Без snap grid непрерывен, геометрия выбирается
явно; координаты до UI не округляются. Предпочтение — QSettings maps/measurement,
не копия масштаба карты. В текущем accepted drag snap не было; новый скрытый snap
не добавлен. Стрелка привязана к реальному якорю TokenItem, clamp совпадает с commit.
Drop/Escape/lost grab/focus очищают transient. Один прежний commit/Undo, нет writes
на mouse move. Player получает transient лишь при видимом слое и полностью открытом
коридоре с footprint обоих концов; при неизвестной/закрытой видимости не получает
ни координаты временного сегмента, ни его ghost. Изменение fog переоценивает публикацию.

MapShape/MapPortal — immutable UUID records в domain/map_document.py. Формы circle,
triangle, rectangle, quadrilateral, cone, polygon. Конус: base width=length, circle
не превращается в ellipse. Все размеры/стили/points finite+bounded, scale>0,
3+разные вершины, ненулевая площадь, нет самопересечений,512vertices и10000records/map.
Прямоугольник сохраняет прямые углы. Validate creation/generic replacement/load,
UUID collisions и refs идут через прежний итоговый валидатор. У портала self-link и
существующая target wrong kind запрещены; удалённая цель остаётся soft ref с диагностикой.

ui/map_vectors.py — Maps-owned native toolbar/gestures/Inspector. One gesture→one
MapsService.put_vector/delete_vector→MapEdit. Undo меняет только touched UUID/component,
не заменяет чужие fog/HP/token/portal. Circle/cone uniform resize; Alt сохраняет
пропорции произвольных фигур, Shift удерживает центр bounding box; rotate Shift15°.
Local inverse transform корректен после поворота, при пересечении anchor clamp>0.
Вершины редактируются отдельным режимом. Inspector: название, native color picker,
проценты непрозрачности, поворот; ожидаемая версия фигуры защищает чужую правку.
Общий Inspector предоставляет нейтральный feature-page API; composition root завершает
предыдущий semantic owner. Cards binding не перехватывает эту страницу фоновым refresh.

Фигуры и подписи рисуются ПОСЛЕ fog в foreground. Прозрачная заливка смешивается
с чёрным, не вырезает fog. Preview/handles/portal GM-only; Player получает только
committed public geometry/style/name. Размеры фигур всегда геометрические, живо
зависят от MapGrid. Ручки и подписи в logical screen pixels, не растут с zoom.
Захват первой вершины10logicalpx, подсветка и замыкающий preview; без дублирования.
Native SVG icons — свои, без dependencies или чужих изображений.

Portal picker использует публичный EntityQueries/EntityPicker: поиск, путь, UUID.
Только OK всех шагов создаёт запись; label пустой означает live название цели.
ПКМ — перепривязка/подпись/удаление, drag — перемещение, double-click — открыть цель.
Player retarget сохраняет тот же top-level/fullscreen/экран; старые tiles/camera/model
сбрасываются в blackout до coherent target. Старые callbacks не могут опубликовать
другую карту: ключи окна/cancel и presentation map_id проверяются существующим lifecycle.
Закрытый Player не запускается. Циклы порталов не вызывают рекурсивного открытия.

MapPortrait — QWidget overlay текущего viewport, один transient session в MapsController.
ПКМ токена получает asset из resolve_token, включая override, без crop/рамки/названия.
Скрытый источник требует Yes; отмена не пишет данные. Shared MediaService декодирует
асинхронно: действуют32MP/64MiB и1024long-edge preview/16MiB cache limits; огромный
источник получает ошибку, не full-size decode в GUI. Fit aspect и native close/Escape
общие для обеих копий, повторный вызов заменяет state. Map/project/window/source deletion
закрывают показ; поздний ready только перерисовывает живой overlay, не воскрешает session.
Показ не сохраняется и не входит в Undo. Это намеренно bounded1024 preview исходного
asset; не обещается оригинальная pixel resolution на4K-мониторе.

## Хранение и совместимость

SQLite16/Card7/Actor1/Rules1(profile2)/Table3/UIstate4 сохранены. Map8 добавляет
objects/shapes/portals envelope внутри прежней JSON-колонки objects; отдельной БД,
таблицы writer или Entity kind нет. Map7 читается с прежним objects list и пустыми
новыми коллекциями. Hash test подтверждает: load не пишет файл и сохраняет Card/Actor
UUID. Следующий обычный save пишет Map8. Старый EXE безопасно отвергает Map8; новый
отвергает Map9. SQLite15 по прежнему контракту не поддерживается. Новое чтение Map7
требуется именно этим пакетом для актуальных миров; универсальные legacy adapters
и автоматическая перезапись на open не возвращались.

Backup/reopen проверяют shapes/portals целиком. Все данные в одном snapshot transaction;
новая инъекция failure при вставке второй карты проверяет rollback первой, включая
новую фигуру. Новые derived feet, handles, arrows и portrait в файле отсутствуют.

## Короткая инструкция ручной приёмки

1. Создать новый disposable проект либо открыть копию актуального SQLite16/Map7 мира.
Задать «Сетка»→футов на клетку5; проверить оба режима расстояния, диагональ, Escape.
2. «Фигуры и порталы»→выбрать тип; круг/конус/rectangle тянуть, triangle/quad ставить
вершинами, polygon замыкать на первой. Выбрать фигуру, нижняя ручка resize, верхняя
rotate; режим «Вершины» отдельно. Alt/Shift, Inspector цвет/название/opacity, Undo.
3. Открыть Player и покрыть карту fog: фигуры и их подписи видны, GM handles/portal
и скрытые токены не видны. Во время drag пересечь fog, изменить fog; не должно быть
публичных числа/ghost/сегмента. Проверить внешний вид100–200% и другой монитор.
4. «Портал»→точка→поиск цели/OK→подпись/OK. ПКМ — правка; double-click — переход.
Проверить тот же Player fullscreen на втором экране; закрытый Player не открывается.
5. ПКМ токена→«Показать картинку», включая override и crop. Подтвердить раскрытие
скрытого источника; закрыть любую копию/Escape, заменить картинку, сменить карту.
6. Save/reopen/backup, удалить target portal и перепривязать. Повторить на чистой
Windows без Python отдельно (I5/ARU-64); не отмечать этот пункт по portable smoke хоста.
