# ARU-77 — трансформация токенов «Объект»

26.11.2026. Локальные изменения для LODANDSY v0.01.

## Карта

- В режиме выбора одиночный токен «Объект» получает рамку, четыре угловые ручки
  размера и отдельную ручку вращения. Оформление и расчёты жестов общие
  с интерактивными фигурами.
- Угол меняется вокруг центра. Shift переключает привязку с шагом 15°.
  Размер изменяется в локальных осях повёрнутого токена. Alt сохраняет
  пропорции, Shift удерживает центр, вместе действуют оба модификатора.
  Размер хранится в дробных клетках. Ограничения задаёт представимость
  положительной конечной геометрии.
- Escape отменяет предпросмотр. Завершённый жест занимает одну позицию
  Map Undo. Геометрия принадлежит размещению `TokenInstance`.
- Попадание и путь движения под туманом проверяют повёрнутую геометрию.
  Рамка, ручки и предпросмотр остаются в представлении ведущего.
  Презентация получает завершённое изменение.

Затронуты `domain/map_document.py`, `domain/document_payloads.py`,
`application/maps_service.py`, `application/maps_controller.py`,
`application/project_actions.py`, `application/sqlite_project_store.py`,
`ui/map_annotations.py`, `ui/map_vectors.py`, `ui/map_widget.py`.

## Формат карт и резервная копия

SQLite17 сохранён. Старые карты открываются без записи. Для первой записи
новой геометрии в существующем мире применяется Map10 и создаётся проверенная
копия `LODANDSY-before-Map10-*.lodbackup` рядом с папкой проекта. Запись базы
и проверка целостности выполняются в одной транзакции. Формат и поведение при
сбое описаны в [ADR-036](../adr/036-map-interactive-tools.md) и
[ADR-040](../adr/040-managed-projects-v001.md).
