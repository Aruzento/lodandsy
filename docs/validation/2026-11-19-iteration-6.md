## Windows UI и непроверенное

Новый exe запускается, native QPA/font database185families/Segoe UI доступен. Windows
computer-use helper запускает/видит окно и accessibility; screenshot capture дважды
завершился `window capture timed out: timed out waiting on channel`, в том числе после
fresh window binding. Настоящий screenshot не получен. Ctrl+O открыл native folder picker; Alt+D не изменил наблюдаемый focus, set_value отказал: `Cannot set a value for an element that is not settable`. Открытие проекта через OS automation не объявляется пройденным. Qt-render собственного синтетического
мира использован только для проверки layout, не выдан за physical capture; private mock
portrait не использован. Offscreen font database0 объясняет glyph boxes в первоначальном
автоматическом render; Windows font backend работает, runtime fallback не добавлялся.

Не проверены физические100/125/150%/mixedDPI/второй монитор, субъективная читаемость/focus/
docking/mouse gestures новой полной сборки и чистая Windows без Python. На host Python
установлен; PATH isolation не считается закрытием ARU-64. [Ручной checklist21пункт](../../build_support/README.md)
покрывает6исходных требований,2дефекта аудита и mandatory input/object-library/layers addendum.
