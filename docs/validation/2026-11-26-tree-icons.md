# ARU-26 · Иконки дерева в LODANDSY v0.01

26.11.2026. Локальная сборка поверх проверенного кандидата v0.01.

Проекция дерева передаёт тип из канонического payload карточки. Все 12 типов
используют SVG 16 logical px с обводкой 1,35, цвет берётся из общего каталога
значков. Оттенки из задания сохранены. На самом светлом фоне выделения
минимальный контраст непрозрачной линии составляет 4,45:1. Текст, фон,
выделение, раскрытие и команды дерева работают через прежний Qt model/view.
Неизвестный тип получает нейтральную иконку Card. Map и Table сохраняют свои SVG.
[Визуальный стандарт](../design/UI-SYSTEM.md#типы-карточек-в-дереве)

Сравнение SHA256 с исходниками предыдущего ZIP подтвердило, что из 124 файлов
приложения изменились только `app_controller.py`, `icons.py`,
`project_tree_model.py` и `tree_panel.py`. SQLite, payload, UUID и модель мира
совпадают с предыдущей сборкой.

## Проверки

Целевой набор дерева и границ модулей: 28 тестов прошли. Регрессии проверяют
различимость силуэтов, цвет в режимах QIcon, нейтральный fallback, оформление
Map/Table, получение типа при создании и повторном открытии, Drag & Drop,
сохранение выбранной и раскрытой строки и переименование.

- Windows QPA: 616 прошли, 1 пропущен. Системная учётная запись не имеет прав
  на создание symlink в тесте путей.
- Offscreen: 615 прошли, 2 пропущены. Дополнительный пропуск связан с активацией
  нативного окна Player.
- Ruff, pip check и `git diff --check` прошли.
- Source smoke прошёл. PyInstaller собрал Windows EXE, 126 модулей сверены
  с исходниками.

Поставка `LODANDSY-v0.01-Windows-Tree-Icons-2026-11-26.zip`. SHA256 и результат
запуска распакованного EXE хранятся рядом с ZIP.
