## A — ARU-69: единый Project Navigator

Дерево отображает Cards с вложенностью, Maps, Tables и Dice. Создание — через «+»
dropdown, поиск — отдельная кнопка/Ctrl+F. У Card нет плюса; дочерняя создаётся через
контекстное меню согласно уточнению владельца по макету. Реальные inline open/menu
доступны выбранной строке без hover. Есть Enter/Insert/F2/Delete/Shift+F10, root/
section/entity menus, parent/order/copy link для Cards. Открытие по kind/ID фокусирует
единственный документ через существующий WindowManager; верхние меню объектов удалены.

ProjectTreeModel хранит только summaries; SQLite и CardCollection не менялись.
Map/Table selection отдельно от Card selection/active document; Inspector — readonly
summary. Удаление закрывает соответствующий документ, остальные остаются. Module
updates адресные, Card-only DnD не допускает карты/таблицы в Card-иерархию.
UI state сохраняет новые keys/expanded/scroll с fallback для прежних файлов.

Файлы: ui/project_tree_model.py, navigator_actions.py, tree_panel.py, card_tree_view.py,
inspector_panel.py, icons.py; application/app_controller.py, module_controller.py,
module_session.py, workspace_state.py; тесты и ADR-007. Старые тесты Card Tree не
удалены: индексы корней перенесены под новый раздел Cards. Найденная регрессия Qt
eventFilter при удалении view исправлена и проверяется полным lifecycle-набором.

Команды: locked-venv Python `-m pytest -q -p no:cacheprovider`, `-m ruff check .`,
`-m pip check`, `git diff --check`. После завершения блока результаты записываются ниже.
Итог автоматической проверки A: 207 passed (7.72 s), Ruff/pip check/diff check успешны.
Кодовая зависимость для B выполнена; ручная приёмка итоговой сборки остаётся открытой,
поэтому статус Linear не подменяется утверждением о пройденном native UX.
GUI-тесты используют настоящий Qt Windows; они не объявляются ручной DPI-приёмкой.
Попытка внешней GUI-проверки: запущенный source AppShell есть в Windows process list,
но не возвращается sky.list_windows(), поэтому UI automation не могла выбрать окно.
Тестовый процесс закрыт, пользовательские приложения/данные не затронуты.

Ручной сценарий итоговой сборки: создать Card/дочернюю/Map/Table через дерево;
кнопками, Enter и меню открыть/переименовать/удалить; проверить фокус/узкую панель,
Card DnD и запрет cross-kind DnD, выбор Inspector отдельно от редактора, restart.
Это открытая часть итоговой Windows-приёмки, не найденная неисправность кода.

## B — ARU-72: панель Markdown и UI typography

После проверки A начаты text range commands и компактная Qt toolbar. Реализованы
H1–H3/normal, bold/italic/strike, quote, lists, inline/fenced code, rule и link dialog;
одна команда — один Undo в прежнем QTextDocument. UTF-16 mapping не смещает emoji и
соседний текст; selection direction, пустые абзацы, несколько строк и embedded ticks
проверены. Клавиши редактора действуют только в focused document. Preview защищён
от format commands; link dialog проверяет URI и escaping, preview network policy прежняя.

Sans/serif/mono и 75–200% scale (включая Ctrl +/- / wheel) меняют только отображение.
Card source не сериализуется в HTML, world revision не растёт. Preferences закрытых
Cards сохраняются как UI DTO и загружаются лениво, без создания всех QTextDocument.

Файлы: application/markdown_commands.py, markdown_links.py; ui/markdown_toolbar.py,
markdown_source_edit.py, card_editor.py, card_document_state.py;
application/app_controller.py/workspace_state.py, test_markdown_commands.py, ADR-008.
Image command намеренно подключается в C вместе с импортом; не добавлена кнопка-заглушка.
Native focus/DPI остаётся в сценарии итоговой сборки; это не отдельная WYSIWYG-модель.
Итог B: полный pytest 241 passed (8.82 s), Ruff/pip check/diff check успешны.
