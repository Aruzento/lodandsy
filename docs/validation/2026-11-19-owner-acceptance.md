## Проверки и оставшаяся граница

До передачи кандидата фактически выполнены: pytest — 293 passed, 1 skipped
(Windows file-symlink privileges); Ruff, pip check, PyInstaller build и frozen smoke
успешны. Frozen smoke включает реальный растр NASA 233 MP, Cards/Map/Tools,
шаблоны, изображения, токены/сетку, save/reopen и восстановление пирамиды после

Эти проверки не запускались повторно ради записи о ручной приёмке.

На отдельный вопрос о запуске именно этого ZIP без установленного Python владелец
ответил: «Пока не проверен без Python». ARU-64 остаётся In Progress. Автоматический
запуск с очищенным Python-окружением на машине с Python не заменяет эту проверку.
Следующий шаг — выполнить сценарий ARU-64 на чистой Windows с тем же ZIP.

Сохраняются ограничения: общий бюджет backup/restore 4 GiB несжатых SQLite+assets;
backup/restore синхронны и на больших архивах могут задерживать интерфейс. Cache
карт производный, в backup не включается. Прочие бюджеты и результаты измерений
остаются в ADR-011/012 и отчёте; приёмка их не отменяет.
