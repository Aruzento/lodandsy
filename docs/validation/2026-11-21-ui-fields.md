`aliases`: сохранён прежний статус служебных данных resolver; новый конструктор или редактор aliases не вводится. `player` скрыт у Object: этот тип уже не разрешён CardsService.set_player. Вход в личный inventory — по ActorRef, вкладка обычного inventory явно подписана как базовый шаблон.

Группы листа: ресурсы/режимы; шесть ability tiles; спасброски; навыки; броня; история хитов по уровням; уровень/опыт/происхождение; атаки; заклинания; игрок; нагрузка/источники. Object показывает только доступные ресурсы/защиту/необязательные abilities. Шесть modifier values и прочие вычисления read-only; введённые параметры идут через shared FieldEdits.
