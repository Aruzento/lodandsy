# LODANDSY — локальный кандидат MVP

Распакуйте всю папку `LODANDSY` в доступное для записи место на Windows 10/11 x64.
Запустите `LODANDSY.exe`; встроенный Python находится в `_internal`.
Не переносите exe отдельно от `_internal`. Полная сборка пока проверена с установленным
Python; её проверка на Windows без Python остаётся открытой (ARU-64).
Эта сборка подготовлена для проверки владельцем, публичный release не опубликован.

1. «Проект → Создать проект» — выберите пустую папку для мира, отдельно от приложения.
   «Открыть проект» выбирает всю папку с `project.sqlite3` и `assets/`.
2. ПКМ в Tree — создать/переименовать/переместить/удалить Card; двойной щелчок — редактор.
   Inspector меняется при выборе в дереве; открытые документы сохраняют контекст.
   Ctrl+F — поиск; source/preview/split и копирование Markdown-ссылки доступны в редакторе.
3. «Карты → Создать карту из изображения» импортирует PNG/JPEG/BMP/GIF/WebP в проект.
   До 16 млн пикселей / 64 MiB на файл. Колесо — zoom, перетаскивание фона — pan.
   ПКМ на карте — маркер; перетаскивайте его, ПКМ — имя/связь/новая Card/удаление.
   Двойной щелчок по маркеру открывает связанную Card. Ctrl+Z/Ctrl+Y работают внутри карты.
4. «Инструменты → Кубики» — NdM±K, результат каждого кубика и итог, повтор и копирование.
   «Создать случайную таблицу» — редактирование, порядок строк, случайный выбор, копирование.
   Пустые строки не участвуют в выборе; все непустые строки имеют одинаковую вероятность.
5. Документы можно закреплять, разделять, объединять во вкладки и отсоединять.
   Закрытие документа сохраняет данные; открывайте его снова через Tree/меню.
6. Autosave и Ctrl+S используют один механизм. Статус снизу показывает ошибки и retry.
   Закрытие и смена проекта предлагают сохранить несохранённые изменения.
   «Резервная копия» сохраняет `.lodbackup` за пределами папки мира.
   Восстановление создаёт новую папку, существующий мир не заменяется.

Мир хранится отдельно от программы. Обновление: распакуйте новую программу в новую папку
и откройте существующую папку мира. Удаление папки программы не затрагивает отдельно
сохранённый мир. Перед сменой версии сделайте backup; миграции БД создают DB-копию в backups/.
Не храните единственную копию мира внутри папки установленного приложения.

## Обязательная сквозная проверка этой сборки

Ручной W2 preflight уже пройден владельцем: чистая Windows без Python, все направления,
CENTER/insert/float/redock, maximize→drag, независимые Cards, layout, мониторы, mixed DPI.
18.11.2026 владелец подтвердил все перечисленные новые сквозные функциональные сценарии:
Card A/B + Map + таблица/кубики, импорт и операции маркеров/связей, таблица и копирование,
сохранение → перезапуск и backup/restore. Эта проверка выполнена с установленным Python.
Для закрытия ARU-64 тот же полный дистрибутив ещё нужно запустить на Windows без Python.
Автоматический frozen smoke и чистый venv такую проверку не заменяют.

Автоматический smoke в новой временной папке (не изменяет пользовательский мир):

```powershell
.\LODANDSY.exe --self-test --report "$env:TEMP\lodandsy-smoke.json"
```

## Воспроизводимая пересборка из source/

Нужны Windows x64 и CPython 3.14.8. Проверенная пара: PySide6 6.11.2 / Qt ADS 5.1.1.

```powershell
py -3.14 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-build.lock
.\.venv\Scripts\python.exe -m pip install --no-build-isolation --no-deps -e .
.\.venv\Scripts\python.exe -m pytest
.\.venv\Scripts\python.exe -m ruff check .
```

Положите LGPL/GPL тексты из `LICENSES/` в `.prototype-deps/license-texts/` исходников.
Их первичный источник: https://github.com/qt/qtbase/tree/v6.11.2/LICENSES .
Затем запустите `build_support/build_windows.ps1`. Набор DLL формируется PyInstaller;
несовместимая ICU78 исключена: Qt использует ICU Windows. Пересборка не публикует release.
Лицензии и ограничения распространения — `THIRD-PARTY.md`.
