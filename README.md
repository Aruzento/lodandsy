# LODANDSY

Большие карты PNG/JPEG/WebP показываются тайлами; импорт имеет progress и отмену.
Исходник хранится в assets, `.lodandsy-cache/maps-v1` можно перестроить при открытии.
Бюджеты: source2GiB, derived cache4GiB/32768tiles на raster, один decoder512MiB,
GUI tile cache64MiB. BMP/GIF сохраняют прежний bounded decoder16MP. Отказ по бюджету
не создаёт карту и не меняет существующие маркеры. Подробнее — ADR-011.

Общий прежний бюджет backup/restore:4GiB SQLite+assets без tile cache. Backup больше
этого объёма отклоняется до публикации; исходный мир и предыдущий архив сохраняются.

Создание Card через плюс или контекстное меню родителя открывает выбор имени и
шаблона: Пустая карточка, Статья, Персонаж, Локация, Предмет. Это независимый Markdown;
свойства персонажа — свободный текст. Существующие карточки шаблонами не заменяются.

Изображение в Card: команда «Изображение» в панели Markdown, вставка из буфера или
перетаскивание одного raster-файла. Укажите alt; файл копируется в assets проекта.
PNG/JPEG/WebP/BMP/GIF: до 64 MiB и 32 MP. Preview показывает ограниченную миниатюру
по ширине окна. Undo удаляет Markdown, ресурс остаётся для других ссылок и backup.

LODANDSY — desktop-приложение на Python и PySide6.

Кандидат MVP: SQLite-проект, дерево карточек с drag-and-drop и порядком,
независимые редакторы по ID, Markdown source/preview/split, поиск и Inspector.
Выбор в Tree меняет Inspector, открытые редакторы сохраняют свой контекст.
Undo/Redo, выделение и прокрутка сохраняются при close/reopen в одной сессии.
Autosave и Ctrl+S используют единый фоновый writer, ошибки видны в статусе с повтором.
Есть резервное копирование/восстановление и защита от второй открытой копии проекта.
Карты с импортом изображений, pan/zoom, маркерами и ссылками на Cards; кубики NdM±K
и пользовательские случайные таблицы открываются независимыми окнами.
Qt ADS владеет размещением окон; Tree/Inspector/rails фиксированы.
Открытые документы, layout, выбор, камера и режим редактора восстанавливаются из
отдельного `.lodandsy-ui.json`. Undo/Redo сохраняется в пределах сессии.
Ручной W2 preflight пройден владельцем 18.11, новые сценарии A–F — 19.11.2026.
Новый ZIP пока не проверен без установленного Python; чистая Windows остаётся ARU-64.

В меню «Проект» создайте проект в пустой папке или откройте существующую папку.
Данные хранятся в `project.sqlite3`, ресурсы — в `assets/`; переносится вся папка.
Без выбранного проекта данные остаются в памяти, при закрытии появляется выбор
сохранить/отбросить/отмена. Восстановление копии создаёт новую папку и не заменяет
существующий мир. Неподдерживаемая версия или kind диагностируются без перезаписи.

Карточки открываются двойным щелчком. Ctrl+F ищет по заголовку и содержимому.
В Source/Split панель редактора применяет Markdown к выделению или текущему абзацу:
H1–H3, bold/italic/strike, quote, списки, inline/fenced code, разделитель и ссылки.
Ctrl+B/I/K и подсказки панели показывают сочетания; Undo/Redo работает по одной команде.
В Preview команды изменения текста недоступны. Пресеты шрифта просмотра и масштаб
(Ctrl +/- или Ctrl+wheel) сохраняются отдельно от содержимого, в том числе для закрытых Cards.
«Копировать ссылку на карточку» даёт готовый Markdown вида
`[Название](lodandsy://card/UUID)`. Preview не изменяет source; изображения разрешены
только из относительного `assets/` текущего проекта. HTTP/HTTPS открываются в системном
браузере только по щелчку. Остальные URI-схемы блокируются.

## Требования

- Windows
- Python 3.14

## Подготовка окружения

Создать виртуальное окружение:

```powershell
py -3.14 -m venv .venv
```

Активировать его:

```powershell
.\.venv\Scripts\Activate.ps1
```

Установить приложение и зависимости разработки:

```powershell
python -m pip install -r requirements-dev.lock
python -m pip install --no-build-isolation --no-deps -e .
```

## Запуск

```powershell
python -m lodandsy.main
```

## Проверки

Запустить тесты:

```powershell
python -m pytest
```

Проверить код через Ruff:

```powershell
python -m ruff check .
```

Проверить зависимости:

```powershell
python -m pip check
```

Без активации окружения используйте `.\.venv\Scripts\python.exe` вместо `python`.

Навигация — через единое дерево «Проект»: «Карточки», «Карты», «Таблицы», «Кубики».
Кнопка «+» над деревом раскрывает создание объектов; рядом — кнопка поиска (Ctrl+F).
Enter/двойной щелчок и кнопка открытия у строки открывают или фокусируют документ по ID.
«…» или Shift+F10 — действия узла; дочерняя Card создаётся через контекстное меню.
Верхние меню объектов удалены, команды проекта сохранены. Удаление требует подтверждения.
Карты создаются из изображения через «+» или меню раздела, ресурсы копируются в assets.
PNG/JPEG/WebP используют bounded tile pyramid (ADR-011); BMP/GIF — legacy decoder16MP.
ПКМ на карте или маркере открывает операции; двойной щелчок по маркеру открывает Card.
«Кубики» и «Таблицы» доступны в дереве проекта. Таблицы сохраняются в проекте;
пустые строки исключены из равновероятного выбора. Результаты кубиков не являются
данными мира; их можно повторить и скопировать.
